# Телеграм-бот для ресторана

Возможности: меню по категориям, корзина, заказ (доставка/самовывоз), бронь стола,
контакты, уведомления администратору с кнопками «Принять/Отклонить».

## Запуск
1. Создайте бота у @BotFather, возьмите токен.
2. `cp .env.example .env` и впишите `BOT_TOKEN` и `ADMIN_CHAT_ID`.
3. `pip install -r requirements.txt`
4. `python bot.py`

Меню и данные ресторана редактируются в `menu.json`. Заказы и брони хранятся в `bot.db`.

## Фото блюд
Фото лежат в `clients/<клиент>/photos/<id блюда>.jpg`. Нет фото — бот покажет логотип клиента.

## Новый клиент
1. `cp -r clients/yamin-baliq clients/<имя-клиента>`, замените `menu.json`, `logo.jpg`, `photos/`.
2. В переменных запуска: `BOT_TOKEN`, `ADMIN_CHAT_ID`, `CLIENT=<имя-клиента>`, при желании `DB_PATH` (путь к тому с постоянным диском).
3. `python bot.py`

Команды администратора: `/stats` (сегодняшняя статистика), `/stop` (стоп-лист блюд).
Команды администратора: `/orders`, `/export`, `/broadcast текст`, `/promo КОД ПРОЦЕНТ`, `/promo off КОД`.
`ADMIN_CHAT_ID` принимает несколько id через запятую.

## Группа курьеров
1. Создайте группу в Telegram, добавьте туда бота и курьеров.
2. Узнайте id группы (например, добавьте в неё @userinfobot или @getidsbot) — он отрицательный, вида `-100123456789`.
3. Задайте переменную `COURIER_CHAT_ID`.
Теперь в заказе с доставкой после «Принять» появляется кнопка «📦 Передать курьеру». Заказ уходит в группу, курьер нажимает «🙋 Беру заказ», клиент получает имя курьера, потом «✅ Доставлено» закрывает заказ и просит оценку.

## Оплата переводом на карту
В `menu.json` → `restaurant.card` укажите `number` и `holder`. Клиент выбирает «Перевод на карту», получает сумму и номер карты, присылает скриншот чека. Администратор видит скриншот с кнопками «Оплата пришла» / «Оплаты нет». После подтверждения заказ принимается (и уходит курьерам, если настроена группа).

## Яндекс Доставка
Переменная `YANDEX_DELIVERY_TOKEN` (OAuth-токен из личного кабинета dostavka.yandex.ru → вкладка «Интеграция») включает автоматический вызов курьера:
после подтверждения заказа с доставкой (кнопка «Принять» или «Оплата пришла») бот создаёт заявку (claims/create, auto_accept), опрашивает статус каждые 30 секунд
и сообщает клиенту о курьере и доставке. Адрес и координаты ресторана — в `menu.json` → `restaurant.yandex.pickup`.
Если Яндекс не нашёл курьера или вернул ошибку, администратору приходит сообщение с кнопкой «Передать курьерам».

## Админ-панель в боте
Кнопка «⚙️ Настройки (админ)» или `/settings`: цены блюд, фото блюд, номер карты и имя владельца, телефон, адрес, часы работы, стоимость доставки, порог бесплатной доставки, минимальный заказ. Значения хранятся в базе (`overrides`) и переживают перезапуск.

## Команды администратора
`/orders`, `/order N`, `/msg N текст` (написать клиенту), `/report [today|week|month|all]`, `/stats`, `/stop`, `/export`, `/settings`,
`/pause` `/resume` (приём заказов), `/ban ID` `/unban ID`, `/broadcast`, `/promo`, `/admins` `/addadmin` `/removeadmin`.
Заказ с оплатой переводом создаётся в момент показа карты (статус «ждём оплату», админу приходит сообщение сразу); без чека за 30 минут он отменяется автоматически.

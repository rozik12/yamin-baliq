# Универсальная платформа Telegram-ботов

Один бот обслуживает много заведений («пространств»). Клиент попадает в заведение по ссылке `t.me/БОТ?start=slug`.
У заведения свой набор модулей, свои админы и свои данные; чужие данные недоступны (проверено тестами).

## Модули (`MODULES=recruiter,shop,booking,leads,support`)
- `shop` — каталог, корзина, заказ (доставка/самовывоз, геолокация), оплата наличными или переводом на карту со скриншотом, статусы, отчёт.
- `booking` — услуги, свободные слоты, подтверждение админом, напоминание за час, отчёт.
- `leads` — форма заявки (темы, имя, телефон, сообщение), воронка статусов, ответ клиенту, отчёт.
- `recruiter` — вакансии, отклики с резюме, статусы с уведомлением кандидату, отчёт.
- `support` — FAQ и обращения к оператору с ответом из бота.
Одному заведению можно подключить несколько модулей: `/newspace slug shop,support Название`.

## Команды владельца платформы
`/newspace slug модули Название`, `/spaces`, `/space slug`, `/delspace slug`, `/setadmin slug id`, `/unsetadmin slug id`, `/newinvite slug`.
Создание заведения выдаёт ссылку для клиентов и одноразовую ссылку админа заведения.

## Запуск
Переменные: `BOT_TOKEN`, `ADMIN_CHAT_ID` (владельцы, через запятую), `MODULES`, `DB_PATH`.
`pip install -r requirements.txt && python main.py`. Тесты: `python -m unittest discover -s tests`.

## Новый модуль
`modules/имя.py`: свой `router`, `core.register_texts`, `core.register_module(имя, клиентские_кнопки, админские_кнопки, cleanup)`,
`core.register_settings`, `core.register_wizard` (пошаговые формы), таблицы с колонкой `tenant`.

## Общие возможности (для любого заведения)
- `/stats` или «📊 Статистика»: клиенты и показатели каждого модуля; у владельца платформы без заведения — сводка по всем.
- `/export` или «📥 Экспорт»: CSV для Excel по модулям заведения.
- Оценки ⭐ после выполненного заказа и записи, предупреждение админу при оценке 1–2.
- `/schedule ГГГГ-ММ-ДД ЧЧ:ММ текст`, `/scheduled`, `/unschedule N`: рассылки по расписанию (часовой пояс заведения, по умолчанию UTC+5).
- Магазин: промокоды («🎟 Промокоды»), кешбэк баллами (настройка «Кешбэк, %») со списанием до 50% заказа и возвратом при отмене.

## Для владельцев бизнеса (без технических знаний)
- Откройте бота и нажмите «🚀 Создать бота для моего бизнеса»: два вопроса (название и чем занимаетесь), и бот готов.
- Бот сразу присылает ссылку, готовый текст для Instagram и QR-код для печати, а также короткий план «что сделать дальше».
- Главных кнопок 3–4, остальное под «⚙️ Ещё»: статистика, выгрузка, настройки, ссылка и QR, добавить сотрудника, помощь.
- Сотрудника добавляют кнопкой «👥 Сотрудник»: одноразовая ссылка. `SELF_SIGNUP=0` закрывает самостоятельное создание ботов.

## Для владельца бизнеса: что работает само
- ☀️ **Утренняя сводка** в 9:00 по времени заведения: записи на сегодня, вчерашние заказы и выручка, что ждёт решения (отключается настройкой).
- ⏰ **Напоминания «не потеряйте клиента»**: заказ без решения 10 минут, запись 15, заявка 30, обращение 30, отклик 60.
- 📣 **Рассылка кнопкой** с предпросмотром и картинкой, плюс `/schedule` для отложенной.
- 👥 **База клиентов**: файл `clients.csv`, новые клиенты за неделю, лучшие клиенты по выручке.
- 🚫 **Выходные дни** для записи, 🎟 промокоды, 💎 баллы и бонус за приглашённого друга, 🔥 популярное и 🔍 поиск для клиентов.

## Для клиентов
«ℹ️ О нас» (описание, адрес, часы, телефон, Instagram, точка на карте), «👥 Пригласить друга» (личная ссылка), «🔁 Повторить» заказ, «🔍 Поиск», «🔥 Популярное».

## Что умеет сверх базового (вторая большая партия)
Общее: статус «🟢 открыто / 🔴 закрыто» по часам работы; вопрос «что улучшить?» при оценке 1–3; автоответ из FAQ на свободный вопрос клиента;
подписка клиентов платформы (`/setpaid slug ГГГГ-ММ-ДД`, предупреждения за 3 и 1 день, автоотключение), `/pausespace`, `/resumespace`, `/backup`;
недельный отчёт по понедельникам; метки источников в ссылках (`ссылка--sinstagram`) и отчёт «Откуда клиенты».
Магазин: минимальный заказ, пауза приёма заказов, остатки товара (лимит, списание, возврат), сохранённый номер телефона, «мы скучаем» (возврат клиентов).
Запись: несколько мастеров (capacity), перерыв между клиентами, обед, минимум времени до записи, горизонт записи, перенос записи клиентом,
напоминание за сутки и за час, автозавершение с просьбой оценить, запись клиента администратором.
Заявки: ответственный («взять себе»), заметки, напоминание «перезвонить», источник заявки.
Рекрутинг: приглашение на собеседование с напоминанием за 2 часа, сообщение кандидату.
